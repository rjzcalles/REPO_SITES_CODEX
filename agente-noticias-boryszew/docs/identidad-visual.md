# Identidad visual de referencia

Paleta contrastada el 26 de octubre de 2026 en https://maflow.com/ y en las hojas de estilo enlazadas por su página de inicio. La interfaz adapta esa paleta a un panel de noticias; no copia la estructura del sitio corporativo.

| Color | Uso en la web de referencia | Uso en la aplicación |
| --- | --- | --- |
| `#282744` | Texto y categorías en el tema | Texto principal y elementos de navegación |
| `#8E1F29` | `.button-red a` y `.button-red input` | Botones y acentos |
| `#C90E19` | Botones al pasar el cursor y enlaces activos del menú | Estados hover y acentos de marca |
| `#A5A4AD` | Separadores y elementos neutros | Separadores y elementos decorativos |
| `#F0F0F2` | Fondo de `body` | Fondo de la aplicación |
| `#FFFFFF` | Superficies y texto de botones | Tarjetas y texto de botones |

Los textos secundarios usan un gris más oscuro (`#666674`) para conservar legibilidad; no se usa el gris claro de marca para párrafos pequeños sobre blanco. Los avisos mantienen colores semánticos diferenciados.
