# Agentes de noticias

Este repositorio reunirá proyectos independientes de agentes de noticias. Cada agente tendrá su propia carpeta, documentación, configuración y reglas de funcionamiento.

## Estructura prevista

```text
REPO_SITES_CODEX/
├── README.md
├── agente-noticias-boryszew/
│   ├── AGENTS.md
│   └── README.md
└── agente-noticias-ia-maflow/
    ├── AGENTS.md
    └── README.md
```

Las carpetas y sus archivos se crearán al desarrollar cada proyecto.

## 1. Agente de noticias sobre el grupo Boryszew

**Carpeta:** `agente-noticias-boryszew/`

Su objetivo será mantenernos actualizados sobre las novedades del grupo Boryszew y sus empresas: noticias corporativas, operaciones, inversiones y otros acontecimientos relevantes.

Será el primer agente que se desarrollará.

## 2. Agente de noticias de IA para Maflow

**Carpeta:** `agente-noticias-ia-maflow/`

Su objetivo será conocer las últimas noticias del mundo de la inteligencia artificial y destacar las novedades que puedan ser relevantes para Maflow.

## Reglas por proyecto

- Cada carpeta contendrá un archivo `AGENTS.md` con las instrucciones específicas de su agente.
- Cada agente seguirá las reglas de su proyecto, incluyendo fuentes, criterios de selección de noticias, idioma, frecuencia y formato de los resultados cuando se definan.
- El `README.md` de cada proyecto explicará su objetivo, configuración y uso.
- El código, las dependencias y la configuración de cada agente se mantendrán dentro de su carpeta.
- Las credenciales se gestionarán mediante la configuración segura del entorno y no se guardarán en el repositorio.

Los detalles de funcionamiento de cada agente se concretarán durante su desarrollo.
